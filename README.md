Project Documentation

Project Overview

This project is a modern web application built with React, TypeScript, Vite, Tailwind CSS, and shadcn/ui.

Getting Started

Prerequisites

- "Node.js" (https://nodejs.org/)
- npm
- Git

Installation

1. Clone the repository

git clone <YOUR_GIT_URL>

2. Navigate to the project directory

cd <YOUR_PROJECT_NAME>

3. Install dependencies

npm install

4. Start the development server

npm run dev

Open the local URL displayed in your terminal to view the application.

Technology Stack

- Frontend: React
- Language: TypeScript
- Build Tool: Vite
- Styling: Tailwind CSS
- UI Components: shadcn/ui

Build for Production

Generate an optimized production build:

npm run build

The production files will be generated in the "dist" directory.

To preview the production build locally:

npm run preview

Deployment on Hostinger

This project can be deployed using Hostinger hosting.

Option 1: Hostinger Web Hosting

1. Install the project dependencies locally.
2. Run "npm run build".
3. Open the "dist" directory generated by the build.
4. Upload the contents of the "dist" directory to the "public_html" directory of your Hostinger domain using File Manager or FTP.
5. Ensure that "index.html" is directly inside "public_html".
6. Configure SPA routing if the application uses client-side routes.
7. Open your domain and verify that the application works correctly.

Important: Standard static hosting serves the built frontend files. If the application requires a backend server, API routes, or server-side rendering, those components must be deployed separately to a compatible environment.

Option 2: Hostinger VPS

For applications requiring a Node.js server or additional backend services, use a compatible Hostinger VPS environment. Configure the server, install the required dependencies, and set up the application process and domain routing.
