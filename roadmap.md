# Website launch checklist

- [ ] Run the SEO and security audits and record current findings.
- [ ] Complete missing technical SEO, metadata, sitemap, redirects, and structured data.
- [x] Complete UX, accessibility, forms, compliance, and performance fixes that are actionable in the codebase.
- [ ] Verify public routes, links, responsive behavior, headers, and production build.
- [ ] Re-audit and summarize completed items plus external actions still required.
